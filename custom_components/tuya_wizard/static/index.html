Tuya Wizard

The UI for Tuya Wizard is under construction.
The backend API is fully operational — devices can be discovered and provisioned via the REST endpoints below.

  • POST /api/tuya_wizard/discover — discover devices
  • GET /api/tuya_wizard/devices — list provisioned
  • POST /api/tuya_wizard/provision — add to LocalTuya
  • POST /api/tuya_wizard/remove — remove device
  • GET /api/tuya_wizard/card_templates — card templates
