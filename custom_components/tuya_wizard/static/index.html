☁️ Bloquear a nuvem por aparelho

Antes de bloquear, saiba:
  • Pode vazar. O bloqueio desvia o tráfego do aparelho pelo Home Assistant, mas o roteador ainda responde a ele de vez em quando, e nessas janelas uma mensagem escapa para a nuvem. Use "Verificar vazamento" depois de algumas horas.
  • Câmeras Tuya podem parar de detectar movimento. Elas conferem o certificado da nuvem e não aceitam o Home Assistant no lugar dela; muitas só geram o evento de movimento depois de falar com a nuvem. Para câmeras, prefira a detecção do Frigate.
  • Se o Home Assistant ou o Companion parar, o bloqueio para (a nuvem volta) e é refeito sozinho quando eles voltam.
  • Para parear de novo ou atualizar o firmware, libere a nuvem e bloqueie de novo depois.
Bloqueio firme no roteador (recomendado junto)
  1. Reserve um IP fixo para o aparelho no DHCP do roteador (pelo endereço MAC).
  2. Crie uma regra de firewall que bloqueie a internet desse IP (tráfego da rede local para a internet, TCP e UDP). O aparelho continua acessível na rede de casa.
  3. Vivo / MitraStar: Configurações avançadas → Firewall → Regras → "Rejeitar do Local", IP de origem = o do aparelho, máscara 255.255.255.255.
  4. TP-Link: Segurança → Controle de acesso (ou Controle dos pais) → bloquear o aparelho para a internet.
  5. Intelbras: Firewall → Filtro de IP/MAC → bloquear o IP de origem para a WAN.
  6. OpenWrt: Rede → Firewall → Regras de tráfego → origem lan com o IP do aparelho, destino wan, ação reject.
  7. Alternativa mais fácil, se o roteador tiver: uma rede Wi-Fi só para aparelhos inteligentes, sem acesso à internet.
